# RCI-FW and RCI-FW-Exact

`rci_fw.cpp` implements RCI-FW and its exact-certification version, RCI-FW-Exact, from the paper.

## Input format

The first line of a graph file is:

```text
m n
```

The next `m` lines contain undirected edges `u v`. Vertex IDs must be in the range `0` to `n`; graph files generated by the root-level `process_adjacent_list.cpp` can be used directly.

The first line of a query file is the number of queries. Each subsequent line contains one reference set `R`, with vertex IDs separated by commas. Compatible query files can be generated with the root-level `generate_R.cpp`; see the root README for its usage.

```text
2
1,5,8
12,13,14,20
```

## Compile

Run the following command from the repository root:

```bash
g++ -O3 -march=native -std=c++17 RCI/rci_fw.cpp -o rci_fw
```

## Run

Run RCI-FW:

```bash
./rci_fw graph.txt queries/rci.txt --max_iters=500 --check_period=50 --exact=0
```

Run RCI-FW-Exact:

```bash
./rci_fw graph.txt queries/rci.txt --max_iters=500 --check_period=50 --exact=1
```

The program writes CSV-formatted results to standard output, with one row per query.

## Parameters

| Parameter | Meaning | Default |
| --- | --- | ---: |
| `--max_iters=N` | Maximum number of Frank--Wolfe iterations for each query. | `500` |
| `--check_period=N` | Run a sweep every `N` Frank--Wolfe iterations. The approximate phase stops early when the sweep solution no longer improves. | `50` |
| `--exact=0\|1` | `0` runs RCI-FW; `1` runs the exact phase after RCI-FW and produces RCI-FW-Exact. | `0` |
